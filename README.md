# 🧮 KALKULATOR ARSITEK ANTI BONCOS
> Dari psikologi yang nyasar belajar Python basic, malah jadi app arsitek.

Aplikasi kalkulator luas, keliling, estimasi biaya bangun + analisis kepribadian ruangan + denah otomatis + laporan PDF 2 halaman.

### ✨ Fitur Gokil
- Hitung mode Rumah / Hotel / Kompleks (max 150 kamar)
- Estimasi biaya Rp / m²
- Analisis Kepribadian Ruangan (Psikologi)
- Gambar denah otomatis + pintu + jendela
- Tanda tangan digital langsung di app
- Export PDF 2 Halaman (Laporan + Denah)
- Watermark DRAFT on/off
- Dark mode 🌙

### 🚀 Cara Jalanin di Laptop
1. Install bahan: `pip install -r requirements.txt`
2. Jalanin: `streamlit run kalkulator.py`
